# Issue tracker

Issues live in **GitHub Issues** for `maruf03/take-home-assignment`. Agents use the `gh` CLI
(`gh issue list`, `gh issue create`, `gh issue view`).

- PRs as a request surface: **off**.
- Link each issue to its plan task (`docs/superpowers/plans/…#task-n`) and its requirement IDs
  (`R#` / `I#`) where it has them.
